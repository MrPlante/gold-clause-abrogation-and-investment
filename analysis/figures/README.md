### Macro data (versioned)

`figures/source-data/macro_monthly.csv` (monthly, 12/1930-12/1936), primary
sources: FX = Banking & Monetary Statistics 1914-1941, Table 173 (monthly
noon buying rates, cents per pound/franc; FRASER), cross-validated against
a vector extraction of the original figures; CPI = FRED `CPIAUCNS` raw
levels (normalized to 12/1932 in code); gold purchasing-program and
official prices with documented program anchors. Full provenance in the
`macro_plots.py` docstring and DISCREPANCIES.md D-015.

### Hickman data (versioned)

`figures/source-data/hickman_industrial_bonds.csv` (columns `year,par_millions`) is
checked in. It is a transcription of Hickman (1953), Appendix A, Table A-2
(straight corporate bonds), Industrials panel, "Offered during year",
1920--1940, millions of dollars par value (NBER chapter scan:
nber.org/chapters/c3090). Verified 2026-07-17 against a calibrated pixel
extraction of the original manuscript figure: all 21 years agree within
4.5 USDm (rendering error). Note the manuscript currently ships the
original TikZ-styled figure; the builder's matplotlib version has the same
data but different styling.

The retired Stata cross-check for the parallel-trend figure
(`export_parallel_trend_figure.do`) lives in git history.
