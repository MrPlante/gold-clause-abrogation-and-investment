# Manuscript figures

## Regenerate

From the repository root:

```bash
code/.venv/bin/python code/run.py --stage figures
```

Outputs are written to:

- `code/output/figure/`
- `manuscript/figures/body/`
- `manuscript/figures/online-appendix/` (existing static files only)

### Hickman data (versioned)

`figures/data/hickman_industrial_bonds.csv` (columns `year,par_millions`) is
checked in. It is a transcription of Hickman (1953), Appendix A, Table A-2
(straight corporate bonds), Industrials panel, "Offered during year",
1920--1940, millions of dollars par value (NBER chapter scan:
nber.org/chapters/c3090). Verified 2026-07-17 against a calibrated pixel
extraction of the original manuscript figure: all 21 years agree within
4.5 USDm (rendering error). Note the manuscript currently ships the
original TikZ-styled figure; the builder's matplotlib version has the same
data but different styling.
